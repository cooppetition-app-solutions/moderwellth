# Modern Wellth: social content

Social media posts and graphics for Modern Wellth (LinkedIn, Facebook, Instagram).

- `social/six-pillars/`: current series built on the six pillars of a Wellthy life (Health & Wellbeing, Purpose, Growth, Community, Relationships, Joy). `posts.md` has the copy; `images/` has a 1080×1080 graphic per post plus a 1080×1920 Story for post 10.
- `social/four-pillars/`: earlier series built on Support, Learning, Events and Community.

The LinkedIn versions of the six-pillar posts are saved as drafts in Buffer; the Facebook and Instagram versions are saved as Buffer Ideas.
